# shop-shipping

A small in-memory web-shop domain: catalog, pricing, shipping, orders, users and reports.
No dependencies. Run the tests with `npm test`.

    src/utils      units, validation, ids, dates
    src/catalog    products, repository, search
    src/pricing    VAT, discounts, line prices
    src/shipping   parcels, rate bands, zones
    src/orders     cart, fulfilment, checkout, status machine
    src/users      users and repository
    src/reports    sales and inventory summaries
